01 — Overview

What is FluxDrop?

FluxDrop is a browser-based, peer-to-peer file transfer tool that sends files directly between two devices — without uploading to any server, cloud, or third-party service.

🌐

Browser-Native

Runs entirely in your browser. No app install, no plugins, no extensions. Just open a URL.

🔒

End-to-End Encrypted

Files are encrypted with AES-256-GCM before leaving the sender's device. Only the receiver can decrypt them.

📡

True P2P

Files travel directly from sender to receiver over WebRTC. No intermediate server stores or relays file data.

♾️

No Size Limits

Transfer any file of any size. No 2GB cap, no upload queue, no waiting for server processing.

02 — Process

How It Works

1

Sender Generates QR

The sender clicks "Start Session" and FluxDrop generates an ECDH P-256 key pair. The public key is encoded into a sequence of animated QR frames displayed on screen.

2

Receiver Scans QR

The receiver points their phone camera at the animated QR. The app collects all frames, reassembles the sender's public key, and generates its own key pair.

3

Key Exchange

Both devices independently derive the same AES-256 key using ECDH (Diffie-Hellman). The receiver sends their public key back via WebSocket signaling. No key ever travels in plaintext.

4

P2P Connection

WebRTC establishes a direct encrypted data channel between the two devices. The signaling server is no longer needed — it only helped with the initial handshake.

5

Encrypted File Stream

The sender reads the file in 64KB chunks, encrypts each chunk with a fresh random IV, and streams it directly to the receiver. SHA-256 integrity is verified on completion.

03 — Technology

Technology Stack

🔗

WebRTC

Browser-native P2P protocol for direct device-to-device data transfer. Uses ICE/STUN for NAT traversal.

Data Channel
🔐

WebCrypto API

ECDH P-256 key exchange + AES-256-GCM authenticated encryption. Fresh random IV per chunk.

ECDH + AES-GCM
📱

Animated QR

Multi-frame QR encoding using qrcode-generator. ZXing library for camera scanning. Sequence-based reconstruction.

qrcode-generator + ZXing
⚡

WebSocket Signaling

Node.js + ws library. Relays connection metadata only (offers, answers, ICE candidates). Never sees file data.

Node.js + ws
✅

SHA-256 Integrity

Cryptographic hash computed on sender, verified on receiver. Detects any corruption in transit.

Integrity Verification
🌐

Cloudflare Tunnel

HTTPS reverse proxy for mobile access. Provides secure context required by WebCrypto on phones.

05 — Features

Special Features

♾️

No Server Limits

No 2GB server cap, no upload queue. Files stream directly between devices. Practical limit depends on device memory (recommended under 2GB).

🧊

QR Freeze on Connect

When P2P connects, the animated QR freezes and shows a connection overlay. Resumes automatically if disconnected.

📥

Drag & Drop

Drag files directly onto the drop zone — no need to browse through file dialogs.

📊

Real-Time Progress

Live progress bar, byte counter, and transfer speed (MB/s) update in real-time during transfer.

🔄

Auto-Reconnect

WebSocket signaling auto-reconnects up to 5 times with exponential backoff if the connection drops.

🛡️

Input Validation

Server validates room IDs, roles, and prevents path traversal. Heartbeat pings detect dead connections.
